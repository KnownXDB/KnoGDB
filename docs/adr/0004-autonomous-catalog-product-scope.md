# ADR 0004: Catálogo autónomo y alcance del MVP

- Estado: aceptada
- Fecha: 2026-10-12

## Decisión

Nombrar el producto KnoGDB (Known Games DataBase), bajo la organización KnownXDB.
El repositorio canónico será KnownXDB/KnoGDB. KnownXDB representa Know, una entidad
X y DB, con capacidad de organizar verticales independientes. Nombres futuros son
tentativos y no forman parte del alcance implementado.

Priorizar catálogo desktop con identidad interna, releases e información localizada.
Incluir administración robusta y scaffolding público, assets moderados, contexto
temporal y planes API administrables. Reservar multimedia para fases posteriores.
PRODUCT-PLAN.md documenta los requisitos acordados.

## Consecuencias

La documentación precede la transferencia y el renombrado autorizados. Estos
cambios no implementan el servicio. Los modelos detallados, cifras de
cuotas y algoritmos deben concretarse antes de las migraciones.
