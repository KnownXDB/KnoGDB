# ADR 0003: Gobernanza del repositorio abierto

- Estado: aceptada
- Fecha: 2026-10-12

## Decisión

Adoptar MIT para código y documentación original, por elección del autor
Mauricio Vuljevas. Separar derechos de datos, medios y marcas. Documentar
seguridad, revisión por PR y Gitflow con promociones explícitas.
Mantener la visibilidad privada durante la preparación.

## Consecuencias

MIT permite forks y uso comercial con atribución; no garantiza exclusividad.
La prevención de secretos requiere capas y revocación. No prometer ausencia
absoluta de exposición. Las protecciones dependen de configuración y plan remoto.
No declarar un requisito implementado solo porque esté documentado.
